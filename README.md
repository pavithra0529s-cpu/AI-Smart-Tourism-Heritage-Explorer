# AI Smart Tourism & Heritage Explorer

## About the Project
AI Smart Tourism & Heritage Explorer is a web application that helps tourists discover heritage places and plan trips with AI assistance.

## Technologies Used
- React.js
- Vite
- Python
- Flask
- Ollama
- SQLite
- Git and GitHub

## Features
- User registration and login
- Password reset
- AI tourism chatbot
- Tourism information with source links
- AI itinerary planner
- Multilingual interface
- Heritage and destination information
- Favorites and search history

## Project Structure
- `frontend/` – React frontend
- `backend/` – Flask backend and APIs
- `data/` – Tourism dataset

## How to Run

### Frontend
Open the terminal inside the `frontend` folder and run:

```bash
npm install
npm run dev
```

### Backend
Open the terminal inside the `backend` folder and run:

```powershell
.\venv\Scripts\Activate.ps1
python app.py
```

### AI Chatbot
Install Ollama and download the model configured in the backend before testing the chatbot.

## Security
Never upload API keys, passwords, or `.env` files to GitHub.
